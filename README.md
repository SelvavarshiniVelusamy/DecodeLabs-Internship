# Password Strength Checker

## About the Project

This is my beginner-level cybersecurity project developed using Python. The main purpose of this project is to check the strength of a password and display whether it is Weak, Medium, or Strong.

## Objectives

* To check the length of a password.
* To check whether the password contains uppercase letters.
* To check whether the password contains numbers and symbols.
* To display the password strength based on the results.

## Technologies Used

* Python
* Visual Studio Code

## Features

* Checks password length.
* Identifies uppercase letters.
* Checks for numbers and symbols.
* Displays the password strength.
* Provides a simple password strength report.

## How to Run

1. Install Python on your computer.

2. Open the project folder in Visual Studio Code.

3. Open the terminal.

4. Run the following command:

   `python password_checker.py`

5. Enter a password when prompted.

6. The program will display the password strength.

## Example Output

```text
=== Password Strength Checker ===
Enter your password: Hello123!

--- Password Strength Report ---
Password Length: 9
Contains uppercase letter: True
Contains number: True
Contains symbol: True
Password Strength: Strong
```
